Nox uses the [Universal Render Pipeline (URP)](https://unity.com/fr/features/srp/universal-render-pipeline),<br/>
which may not be compatible with all shaders available for Unity.

The URP allows to create [Shader Graphs](https://docs.unity3d.com/Packages/com.unity.shadergraph@17.4/manual/index.html) for custom shaders.

## Tested Shaders

<Callout type="warn">
    This list cannot be exhaustive, and can be changed at any time.
</Callout>

Here is a list of shaders that have been tested and are known to be compatible with Nox:

- [Universal Render Pipeline/Lit](https://docs.unity3d.com/Manual/urp/lit-shader.html): The default lit shader in URP, suitable for most materials.
This shader is allready included in Unity Editor with URP.

- [Poiyomi Shader (Discord)}](https://discord.com/invite/poiyomi): A popular shader for avatars, offering a wide range of features and customization options.
You can download if from the Poiyomi Discord server at [#urp-release](https://discord.com/channels/550477546958094348/1389417288880357526).
